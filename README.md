# Tuchi Digital

Website for Tuchi Digital, a digital studio focused on web design, development and digital solutions for businesses.

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* GSAP
* ScrollTrigger

## Features

* Responsive design
* Custom animations and interactions
* GSAP scroll animations
* Responsive navigation
* Services and pricing sections
* Portfolio and client projects
* Team section
* Contact section
* Mobile-first layout

## Getting Started

### Requirements

* Node.js
* npm

### Installation

Clone the repository and install the dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL shown in the terminal.

### Build

Create a production build:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```

## Design

The website follows a modern digital-studio aesthetic focused on typography, whitespace, interaction and motion.

The visual system uses:

* Dark blue `#102A43`
* Cream `#F5F3EE`
* Cyan `#55D6FF`
* Momo Trust Display typography
* GSAP-powered animations and transitions
